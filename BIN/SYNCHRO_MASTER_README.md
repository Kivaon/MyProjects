# TBox Synchro Master v2.0 - Универсальный модуль синхронизации

## 🎯 Назначение

Умный инструмент для визуального сопоставления двух текстовых файлов с автоматическим выравниванием и созданием документа-сверки в формате DOCX.

## 🚀 Запуск

### Базовые команды:
```bash
# Без параметров = Auto-Translate (самый частый режим)
python tbox_synchro_master.py

# Manual mode - указываем файлы вручную
python tbox_synchro_master.py manual file1.txt file2.md

# Auto-Refinery - синхронизация Raw ↔ MD
python tbox_synchro_master.py autoref

# Auto-Translate - синхронизация MD ↔ DOCX
python tbox_synchro_master.py autotr

# Export - извлечение правок из DOCX
python tbox_synchro_master.py export synchro_file.docx corrected.md

# Поиск по фрагменту имени
python tbox_synchro_master.py Beshalah
```

## 📁 Что происходит в разных режимах

### 1. **Auto-Translate** (по умолчанию)
```
python tbox_synchro_master.py
```

**Что делает:**
- Ищет последнюю пару: `02_TXT/MD/*.md` ↔ `03_DOC/TRANSLATED/*.docx`
- Находит файлы по схожести имен (Beshalah_audio.md ↔ Ready_Beshalah_audio.docx)
- Определяет производный файл (обычно DOCX меньше)
- Выравнивает тексты умным алгоритмом
- Создает DOCX с двухколоночной таблицей

**Идеально для:** Сверки перевода с оригиналом

---

### 2. **Auto-Refinery**
```
python tbox_synchro_master.py autoref
```

**Что делает:**
- Ищет последнюю пару: `02_TXT/raw/*.txt` ↔ `02_TXT/MD/*.md`
- Находит файлы по схожести имен (Beshalah_audio_raw.txt ↔ Beshalah_audio.md)
- Сравнивает сырую транскрибацию с обработанной
- Показывает что изменилось при обработке

**Идеально для:** Проверки работы refinery

---

### 3. **Manual Mode**
```
python tbox_synchro_master.py manual /path/to/file1.txt /path/to/file2.md
```

**Что делает:**
- Работает с любыми двумя указанными файлами
- Поддерживает форматы: `.txt`, `.md`, `.docx`
- Автоматически определяет кодировку (utf-8, cp1251, latin-1, utf-16)
- Универсальное решение для любых задач

**Идеально для:** Разовых сравнений, тестов

---

### 4. **Export**
```
python tbox_synchro_master.py export synchro_file.docx result.md
```

**Что делает:**
- Читает созданный ранее DOCX файл
- Извлекает текст только из правой колонки
- Сохраняет как чистый Markdown файл
- Удобно для дальнейшей обработки

**Идеально для:** Сбора правок после ручного редактирования

---

### 5. **Поиск по фрагменту**
```
python tbox_synchro_master.py Beshalah
```

**Что делает:**
- Ищет файлы содержащие "Beshalah" в имени
- Работает в режиме Auto-Translate (если не указано иначе)
- Находит самую свежую пару с этим фрагментом

**Идеально для:** Быстрой работы с конкретным файлом

## 🧠 Умный алгоритм работы

### 1. **Чтение файлов**
- Пробует кодировки: `utf-8`, `utf-8-sig`, `cp1255`, `cp1252`, `latin-1`, `utf-16`
- Определяет язык текста (иврит, русский, английский)
- Нормализует Unicode для иврита

### 2. **Сегментация**
- **Стена текста** → разбивка по предложениям (600 символов)
- **Структурированный текст** → разбивка по абзацам и заголовкам
- Заголовки (`#`) всегда отдельные сегменты

### 3. **Определение производного файла**
```
Если левый ≤ правый:
    Левый = производный, Правый = основной
Иначе:
    Правый = производный, Левый = основной
```

### 4. **Умное выравнивание**
- **Якоря:** заголовки выравниваются в первую очередь
- **Производный → Основной:** для каждого сегмента производного ищется лучший матч
- **Частичные совпадения:** ищет общие последовательности слов (от 3 слов)
- **Окно поиска:** ищет в следующих 5 сегментах при сдвигах

### 5. **Сходство текстов**
```
Высокое: ≥80% (почти идентично)
Среднее: 50-79% (существенные отличия)
Низкое: <50% (разные тексты)
```

### 6. **Создание DOCX**
- **Альбомная ориентация** с минимальными полями (1см)
- **Двухколоночная таблица** с видимыми границами
- **Интеллектуальный BIDI:**
  - Иврит → RTL, шрифт David/New Peninim (macOS)
  - Русский/Английский → LTR, шрифт Times New Roman
- **Автоочистка** от недопустимых XML символов

## 🐛 Возможные проблемы

### Иврит отображается абракадаброй:
- **macOS:** Используются нативные шрифты (David, New Peninim)
- **Кодировка:** Пробуются multiple encodings включая cp1255
- **BIDI:** Усиленная поддержка RTL для macOS Word

### Нет совпадений:
- **MIN_MATCH_RATIO:** Установлен в 0.15 (очень мягкий)
- **Частичные совпадения:** Ищутся последовательности от 3 слов
- **Окно поиска:** 5 сегментов для компенсации сдвигов

### Файлы не найдены:
- **Проверьте пути** в config.txt
- **Используйте manual mode** для точного указания файлов
- **Проверьте права доступа** к директориям
