## 🧪 Сервисная утилита: test-API.py

**Назначение:** Изолированное тестирование работоспособности API-ключа и проверка доступности конкретных моделей без запуска основного процесса перевода.

### Основные функции:

1. **Валидация ключа:** Проверяет, принимает ли Google текущий `API_KEY`.
2. **Сбор ответа (Raw Response):** Выводит в консоль полный JSON-ответ от сервера. Это полезно для диагностики новых ошибок, которые основной скрипт (`translator.py`) может скрывать за упрощенными логами.
3. **Проверка HTTP-статусов:** - `200`: Ключ и модель активны.
* `404`: Модель больше не поддерживается или опечатка в имени.
* `429`: Превышена квота (включая проверку на "Limit 0").



### Когда использовать:

* При получении нового API-ключа.
* Если `translator.py` постоянно выдает ошибки, и нужно понять, проблема в коде или в серверах Google.
* Для быстрого теста новой модели из экспериментальной ветки (`v1beta`).
