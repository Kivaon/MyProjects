# 🏭 AI Lecture Factory: Translator v4.4.smart
**Дата версии:** 2026-01-23  
**Статус:** Стабильный билд (v4.4.smart)

Автоматизированная система обработки и перевода больших лекций (Раввинские лекции) с иврита на русский. Система оптимизирована для работы с длинными текстами, поддерживает умное переключение моделей при исчерпании квот и сохраняет структуру цитирования.

---

## 📂 Архитектура проекта
Проект организован по модульному принципу:

* `ROOT/` — Корень проекта.
* `config.txt` — Конфигурационный файл (API-ключ, целевая модель).
* `bin/` — Исполняемые Python-скрипты.
* `02_TXT/` — Входная папка для исходных текстов (`.txt`).
* `03_DOC/ORIGINAL/` — Сгенерированные документы на языке оригинала.
* `03_DOC/TRANSLATED/` — Итоговые переведенные документы (`.docx`).
* `factory.log` — Системный журнал (отслеживание ошибок и смены моделей в реальном времени).

---

## ⚙️ Логика работы (Алгоритм)

1.  **Инициализация:** Проверка `config.txt`. При отсутствии API-ключа — мгновенная остановка для предотвращения пустых запросов.
2.  **Выбор цели:** Автоматический захват самого свежего файла в `02_TXT` или выбор по аргументу командной строки.
3.  **Chunking (Нарезка):** Текст разбивается на блоки по **10,000 символов**. Это обеспечивает баланс между контекстом для Gemini 2.5/3 и стабильностью API.
4.  **Умный Adaptive Translation:**
    * Основной запрос к выбранной модели.
    * **Auto-Fallback:** При получении ошибок `429` (Quota) или `404`, скрипт запускает `find_working_model()`, сканирует доступные протоколы (Gemini 2.5, 3, Flash Lite) и переключается на «живую» модель на лету.
    * **Retry Logic:** Если все линии заняты, система уходит в режим ожидания (60 сек) и повторяет цикл.
5.  **Форматирование:**
    * Речь автора транслируется в литературный русский.
    * Источники (иврит) обрабатываются согласно флагам (удаление или выделение **Bold + Italic**).

## 🚀 Параметры запуска

Запуск из терминала (находясь в корне проекта):

| Команда | Описание |
| :--- | :--- |
| `python3 bin/translator.py` | Стандартный перевод (только русский текст). |
| `python3 bin/translator.py -s` | Перевод с сохранением иврита (`-s` = source). |
| `python3 bin/check_api.py` | Сервисная утилита: диагностика всех доступных моделей и лимитов. |
