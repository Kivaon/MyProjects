# ABOX - Audio Box
# Полное руководство по системе озвучки текстов

## 🎯 Назначение ABOX

ABOX - это мощная система для преобразования текста в речь (TTS) с поддержкой:
- Русского и иврита
- Предобработки с ударениями
- Кастомных голосов
- Визуализации ударений
- ИИ-улучшения пунктуации

---

## 📁 Структура и модули

### 🎤 Основные TTS скрипты

#### `tbox_tts_gen.py` - Главный генератор TTS
**Назначение:** Улучшенная озвучка с предобработкой и настройками

**Возможности:**
- Поддержка форматов: TXT, MD, RTF, DOCX
- Предобработка текста с ударениями
- Разные методы озвучки (Edge TTS, AI)
- Настройка скорости и голоса
- Автоматическое разделение на части
- Склейка аудио через ffmpeg

**Использование:**
```bash
# Прямой запуск
python3 tbox_tts_gen.py файл.txt

# С параметрами
python3 tbox_tts_gen.py файл.txt --voice=ru-RU-DmitryNeural --speed=slow --method=edge

# Через алиас (если настроен)
speech файл.txt male fast
```

**Конфигурация в aconfig.txt:**
- `DEFAULT_VOICE` - голос по умолчанию
- `AUDIO_DIR` - папка для аудио
- `MAX_CHARS_PER_CHUNK` - размер чанков
- `ENABLE_STRESS_CORRECTION` - исправление ударений

---

#### `tbox_tts.py` - Простой TTS
**Назначение:** Быстрая озвучка без сложной предобработки

**Возможности:**
- Поддержка TXT, MD, DOCX
- Выбор голоса (мужской/женский)
- Автопоиск последнего файла

**Использование:**
```bash
python3 tbox_tts.py [--male|--female] [файл]
```

---

### 📝 Предобработка текста

#### `tbox_tts_preprocessor.py` - Предобработчик TTS
**Назначение:** Подготовка текста для качественной озвучки

**Функции:**
- Расстановка ударений по словарям
- Исправление пунктуации
- Обработка аббревиатур
- Нормализация чисел и дат
- Обработка ивритских текстов

**Словари:**
- `data/dictionaries/stress_basic.txt` - ударения
- `data/dictionaries/abbreviations.txt` - сокращения

---

#### `tbox_punctuation_ai.py` - ИИ для пунктуации
**Назначение:** Улучшение пунктуации с помощью ИИ

**Возможности:**
- Автоматическая расстановка знаков препинания
- Коррекция запятых и точек
- Улучшение читаемости текста

---

#### `tbox_text_marker.py` - Маркер проблемных слов
**Назначение:** Поиск и маркировка сложных для озвучки слов

**Функции:**
- Поиск слов без ударений
- Маркировка иностранных слов
- Выделение аббревиатур
- Создание отчета проблемных мест

**Использование:**
```bash
python3 tbox_text_marker.py файл.txt
```

---

### 🎭 Работа с голосами

#### `tbox_tts_ethalon.py` - Эталонные голоса
**Назначение:** Создание стандартизированных голосов

**Возможности:**
- Создание эталонных голосов для русского и иврита
- Генерация обучающих данных
- Автоматическое создание моделей

**Использование:**
```bash
# Создание эталонного голоса
python3 tbox_tts_ethalon.py --name=russian_ethalon --language=russian

# Эталон иврита
python3 tbox_tts_ethalon.py --name=hebrew_ethalon --language=hebrew
```

---

#### `tbox_voice_trainer.py` - Тренажер голосов
**Назначение:** Создание кастомных голосов из аудио

**Возможности:**
- Извлечение голосовых образцов
- Создание метаданных голоса
- Обучение голосовых моделей
- Управление библиотекой голосов

**Использование:**
```bash
# Список голосов
python3 tbox_voice_trainer.py --list

# Создание голоса
python3 tbox_voice_trainer.py --create lecturer1 --name "Рав Коэн" --source lecture.mp3

# Обучение модели
python3 tbox_voice_trainer.py --train lecturer1
```

---

#### `list_voices.py` - Список доступных голосов
**Назначение:** Просмотр всех доступных голосов

**Использование:**
```bash
python3 list_voices.py
```

## ⚙️ Конфигурация (aconfig.txt)

### Основные настройки:
```ini
# Голосовые настройки
DEFAULT_VOICE=ru-RU-DmitryNeural    # Голос по умолчанию
SPEED=normal                         # Скорость речи
PITCH=medium                         # Высота тона
VOLUME=1.0                           # Громкость

# Пути
AUDIO_DIR=06_AUDIO/IN                # Папка для аудио
VOICE_MODELS_DIR=ABOX/data/models    # Модели голосов
DICTIONARIES_DIR=ABOX/data/dictionaries  # Словари

# TTS настройки
MAX_CHARS_PER_CHUNK=3000             # Размер чанков
OUTPUT_FORMAT=mp3                    # Формат аудио
SAMPLE_RATE=24000                    # Частота дискретизации

# Предобработка
ENABLE_STRESS_CORRECTION=true       # Исправление ударений
ENABLE_PUNCTUATION_FIX=true         # Исправление пунктуации
ENABLE_ERROR_CORRECTION=true         # Исправление ошибок

# Визуализация
ENABLE_VISUALIZATION=true           # Включить визуализацию
VISUALIZATION_FORMAT=html            # Формат визуализации
```

## 🔄 Интеграция с TBOX

### Связь модулей:
1. **TBOX** обрабатывает тексты → создает словари ударений
2. **ABOX** использует словари → качественная озвучка
3. **Общие данные** в `shared/` и `config/`

### Типичный рабочий процесс:
```bash
# 1. В TBOX: обработка лекции
translator lecture.txt

# 2. В ABOX: разметка ударений
marker lecture_translated.txt

# 3. В ABOX: озвучка с предобработкой
speech lecture_translated.txt male slow

# 4. В ABOX: визуализация результата
visualizer lecture_translated.txt
```

## 🎯 Практические сценарии

### Сценарий 1: Озвучка лекции
```bash
# Быстрая озвучка
speech lecture.txt male normal

# Качественная озвучка с предобработкой
python3 tbox_tts_gen.py lecture.txt --voice=ru-RU-DmitryNeural --method=ai_full
```

### Сценарий 2: Создание кастомного голоса
```bash
# Из аудио лекции создаем голос
python3 tbox_voice_trainer.py --create rav_voice --name "Голос Рава" --source lecture.mp3

# Обучаем модель
python3 tbox_voice_trainer.py --train rav_voice

# Используем новый голос
speech lecture.txt CUSTOM:rav_voice
```

### Сценарий 3: Подготовка текста для озвучки
```bash
# Маркируем проблемные слова
python3 tbox_text_marker.py text.txt

# Улучшаем пунктуацию
python3 tbox_punctuation_ai.py text.txt

# Визуализируем ударения
python3 tbox_tts_visualizer.py text.txt
```

## 📊 Метрики и качество

### Качество озвучки зависит от:
- ✅ **Точности ударений** (словари + предобработка)
- ✅ **Чистоты текста** (удаление артефактов)
- ✅ **Правильной пунктуации** (паузы и интонация)
- ✅ **Выбора голоса** (подходящий тембр)
- ✅ **Настроек скорости** (естественная речь)

### Улучшение качества:
1. **Расширяйте словари** ударений
2. **Используйте предобработку**
3. **Выбирайте подходящий голос**
4. **Настройте скорость речи**
5. **Проверяйте результат визуализацией**

## 📞 Поддержка и отладка

### Логирование:
- Все логи в `BIN/_logs/abox.log`
- Уровни: DEBUG, INFO, WARN, ERROR

### Отладка:
```bash
# Проверка конфигурации
python3 -c "import tbox_utils; print(tbox_utils.load_abox_config())"

# Тест голоса
python3 list_voices.py

# Проверка словарей
ls -la ABOX/data/dictionaries/
```

### Частые проблемы:
1. **Нет звука** → проверьте `DEFAULT_VOICE`
2. **Плохое качество** → включите предобработку
3. **Медленно** → уменьшите `MAX_CHARS_PER_CHUNK`
4. **Ошибки импорта** → проверьте пути в `aconfig.txt`
