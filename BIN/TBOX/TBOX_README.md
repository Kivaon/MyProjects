# TBox Translator v6.00 — Обзор и инструкция

## 📋 Описание
**TBox Translator v6.00.hybrid_pro** — гибридный переводчик текстов с автоматическим подбором модели и форматированием результата в Word.

Сочетает:
- 🔄 **Надежность v4.80** — retry-логика, автоматический поиск рабочей модели
- 📝 **Красоту v5.80** — рендер Markdown, форматирование Word, жирный текст

---

## 🎯 Основные возможности

### 1. **Гибкий выбор файла**
- Автоматический поиск последнего файла (по умолчанию `.txt`)
- Ручное указание пути: `python tbox_translator.py /path/to/file.txt`
- Поиск в конкретной директории: `-txt` или `-md`

### 2. **Система промптов**
Встроены 3 профиля перевода:
- **TORAH** — лекции раввина (по умолчанию)
- **FICTION** — художественные тексты
- **GENERIC** — общие текст

Выбор: `python tbox_translator.py -p FICTION`

### 3. **Автоматический подбор модели**
При ошибке 404, 429, 500, 503:
- Автоматически ищет рабочую альтернативу
- Переключается на найденную модель
- Продолжает перевод без потерь

### 4. **Retry-логика**
- 3 попытки на каждый чанк
- 15-сек пауза между попытками
- 12-сек пауза между чанками

### 5. **Форматирование Word**
✓ Центрированные заголовки (#)  
✓ Жирный текст (**)  
✓ Times New Roman 12pt  
✓ Выравнивание по ширине (JUSTIFY)  
✓ Отступы 2см

### 6. **Поддержка оригинала**
Флаг `-s` включает исходный текст цитат в скобках после перевода

## 📂 Структура конфигурации

### Где хранятся промпты?

**Встроенные промпты** (в коде `load_prompts`):
```python
'TORAH': "Ты — редактор лекций Рава {author}. Переведи часть {part_num}/{total_parts} на русский..."
'FICTION': "Переведи художественный текст часть {part_num}/{total_parts}..."
'GENERIC': "Переведи текст часть {part_num}/{total_parts}..."
```

**Внешний файл** (опционально):
- Путь: `07_PROMPTS/prompts.md` (от BASE_DIR)
- Формат: Markdown с заголовками `# CODE`

Пример `07_PROMPTS/prompts.md`:
```markdown
# TORAH
Ты — редактор лекций...

# FICTION
Переведи художественный...

# CUSTOM
Твой кастомный промпт...
```

Если файл не найден → используются встроенные промпты

## 🚀 Команды запуска

### Базовый запуск (последний .txt)
```bash
python tbox_translator.py
```

### Указать файл явно
```bash
python tbox_translator.py /path/to/file.txt
python tbox_translator.py filename.txt  # Ищет в TXT_RAW
```

### Выбрать последний .md
```bash
python tbox_translator.py -md
```

### Выбрать промпт
```bash
python tbox_translator.py -p FICTION
python tbox_translator.py --prompt GENERIC  # Полная форма
```

### Включить оригинал цитат
```bash
python tbox_translator.py -s
```

### Комбинированные опции
```bash
python tbox_translator.py -md -p FICTION -s
```

## ⚙️ Конфигурация (config.txt)

**Требуемые переменные:**
```ini
API_KEY = sk-proj-xxxxx...  # Google API ключ
MODEL_GEMINI = gemini-2.0-flash  # Основная модель

TXT_RAW = 02_TXT/raw  # Входные .txt файлы
MD_DIR = 02_TXT/MD  # Входные .md файлы (для translator и refiner)
TXT_DIR = 02_TXT/MD  # Совместимость со старым кодом
DOC_TRANSLATED = 03_DOC/TRANSLATED  # Выход .docx
ARH_TXT = 05_ARH/TXT  # Архив исходников

BASE_DIR = /path/to/workspace  # Базовая директория
PROMPTS_DIR = 07_PROMPTS  # Где ищут промпты
DEFAULT_PROMPT = TORAH  # Промпт по умолчанию
```

## 📊 Процесс перевода

1. **Загрузка конфига** → читает `config.txt`
2. **Инициализация** → модель из конфига, загрузка промптов
3. **Выбор файла** → автоматический или ручной
4. **Разбиение на чанки** → по 10000 символов
5. **Перевод каждого чанка** → с retry-логикой и автопереключением
6. **Рендер MD** → форматирование в Word
7. **Сохранение** → `Ready_*.docx` в `DOC_TRANSLATED`
8. **Архивирование** → исходник в `ARH_TXT` с префиксом `TR_DONE_`

---

## 🔧 Логирование

Все события логируются через `tbox_log`:
- **START** — начало перевода
- **INFO** — ход работы (номер чанка, попытки)
- **WARN** — предупреждения (ошибки API, смена модели)
- **ERROR** — критические ошибки
- **DONE** — успешное завершение

**Ошибки выводятся в консоль** и в файлы логов (если настроены в `tbox_utils`)

## ⚠️ Что может пойти не так

| Проблема | Решение |
|----------|--------|
| Конфиг не найден | Проверить `config.txt` в корне workspace |
| Нет файлов для перевода | Положить `.txt` в `TXT_RAW` или `.md` в `MD_DIR` |
| Модель не найдена (404) | Проверить `MODEL_GEMINI` в конфиге |
| Ошибка загрузки промптов | Проверить формат `prompts.md`, используются встроенные |
| API Error 400 | Проблема в промпте — проверить format string |
| Rate Limit (429) | Ждет 15 сек, затем меняет модель |
