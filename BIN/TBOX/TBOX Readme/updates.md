# 📄 Модуль: PDF Document Extractor (v4.4.smart)
**Вход:** `.pdf` из `01_PDF/`  
**Выход:** `.txt` в `02_TXT/`

### Назначение
Извлечение текстового слоя из PDF-документов с автоматической коррекцией направления письма (иврит/RTL) с помощью алгоритма BiDi.

### ⚙️ Интеграция
* **Конфиг:** Читает `factory.log` из `config.txt` для ведения единой истории.
* **Именование:** Использует метку времени с секундами `YYMMDD_HHMMSS`, что исключает конфликты при пакетной обработке.
* **BiDi Support:** Исправляет "перевернутый" иврит, который часто встречается при простом копировании из PDF.

### 📅 Roadmap (Будущие версии)
* **OCR Mode:** Добавление распознавания текста (Tesseract/Google Vision) для PDF, которые являются просто набором картинок (сканы).
* **Originals Export:** Параллельное создание `.docx` копии оригинала в `03_DOC/Originals/`.
