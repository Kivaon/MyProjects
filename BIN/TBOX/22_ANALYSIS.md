## 🔄 Алгоритм обработки

### 1. Сегментация страницы
- Страница делится на горизонтальные зоны по 40px высотой
- Каждая зона анализируется отдельно

### 2. Определение колонок
```
gap > 40px = 3 колонки
gap > 35px = 2 колонки  
gap ≤ 35px = 1 колонка
```

### 3. Порядок чтения RTL
```
Для RTL текста:
1. Сортировка колонок: справа → налево
2. Внутри колонки: слова сортируются справа → налево
3. Строки читаются сверху → вниз
```

### 4. Фильтрация шума
- Удалены номера страниц
- Удалены короткие слова (< 2 символов)
- Удалены слова с паттернами (стр., page, ©, www.)
