# TBox Refine Standalone - Гид по промптам

## 🎯 Обзор

`tbox_refine_standalone.py` поддерживает множество режимов обработки текста с разными промптами. Теперь поддерживает **любой язык** на входе и **любой язык** на выходе.

## 📋 Доступные режимы

### 🔄 Многоязычные режимы

#### **MULTILANG** - Универсальный форматер
```bash
python3 tbox_refine_standalone.py input.txt MULTILANG
```
- **Вход:** любой язык (автоопределение)
- **Выход:** тот же язык, отформатированный в Markdown
- **Применение:** форматирование текстов на любом языке

#### **TRANSLATE_TO_RU** - Перевод на русский
```bash
python3 tbox_refine_standalone.py input.txt TRANSLATE_TO_RU
```
- **Вход:** любой язык
- **Выход:** русский, Markdown
- **Применение:** перевод текстов на русский

#### **TRANSLATE_TO_EN** - Перевод на английский
```bash
python3 tbox_refine_standalone.py input.txt TRANSLATE_TO_EN
```
- **Вход:** любой язык
- **Выход:** английский, Markdown
- **Применение:** перевод текстов на английский

#### **TRANSLATE_TO_HE** - Перевод на иврит
```bash
python3 tbox_refine_standalone.py input.txt TRANSLATE_TO_HE
```
- **Вход:** любой язык
- **Выход:** иврит, Markdown
- **Применение:** перевод текстов на иврит

### 🎨 Специализированные режимы

#### **AUDIO** - Аудио транскрипты
```bash
python3 tbox_refine_standalone.py input.txt AUDIO
```
- **Вход:** иврит/русский (транскрипт аудио)
- **Выход:** тот же язык, форматирование
- **Особенности:** сохраняет язык, удаляет слова-паразиты

#### **PDF** - PDF документы
```bash
python3 tbox_refine_standalone.py input.txt PDF
```
- **Вход:** английский (PDF распознавание)
- **Выход:** английский, склеенные строки

#### **PDF_HE** - PDF с ивритом
```bash
python3 tbox_refine_standalone.py input.txt PDF_HE
```
- **Вход:** иврит+русский (PDF)
- **Выход:** исправленный иврит+русский
- **Особенности:** исправляет огласовки (никудот)

#### **YT** - YouTube транскрипты
```bash
python3 tbox_refine_standalone.py input.txt YT
```
- **Вход:** английский (YouTube)
- **Выход:** английский, форматирование

#### **GENERAL** - Универсальный
```bash
python3 tbox_refine_standalone.py input.txt GENERAL
```
- **Вход:** любой язык
- **Выход:** базовое форматирование

## 🎯 Кастомные промпты

### **CUSTOM** - Собственные инструкции
```bash
python3 tbox_refine_standalone.py input.txt CUSTOM:"Переведи на испанский и добавь заголовки"
```

#### Примеры кастомных промптов:

```bash
# Перевод на конкретный язык
CUSTOM:"Переведи текст на испанский язык, сохранив структуру"

# Научное форматирование
CUSTOM:"Оформи текст как научную статью с аннотацией и выводами"

# Литературная обработка
CUSTOM:"Преобразуй текст в художественный рассказ с диалогами"

# Техническая документация
CUSTOM:"Оформи как техническую документацию с инструкциями"

# Сжатие текста
CUSTOM:"Сохрани только основные идеи, убрав воду"

# Расширение текста
CUSTOM:"Добавь подробности и примеры к каждому пункту"
```

## 🔧 Автоопределение языка

В режиме **MULTILANG** система автоматически определяет язык:

### Поддерживаемые языки:
- ✅ **Иврит** - автоматическое определение
- ✅ **Русский** - автоматическое определение  
- ✅ **Английский** - автоматическое определение
- ✅ **Испанский** - автоматическое определение
- ✅ **Французский** - автоматическое определение
- ✅ **Немецкий** - автоматическое определение
- ✅ **Арабский** - автоматическое определение
- ✅ **Китайский** - автоматическое определение
- ✅ **Японский** - автоматическое определение
- ✅ **Корейский** - автоматическое определение

### Логика определения:
```python
1. Проверяются специфические символы языка
2. Подсчитывается количество символов каждого языка
3. Язык с наибольшим количеством символов выбирается
4. Если латиницы > 20 символов - английский
5. Иначе - unknown
```

## 📝 Примеры использования

### 🎧 Обработка аудио на разных языках:

```bash
# Иврит аудио → форматированный иврит
python3 tbox_refine_standalone.py hebrew_audio.txt AUDIO

# Испанское аудио → форматированный испанский  
python3 tbox_refine_standalone.py spanish_audio.txt MULTILANG

# Немецкое аудио → перевод на русский
python3 tbox_refine_standalone.py german_audio.txt TRANSLATE_TO_RU
```

### 📄 Работа с документами:

```bash
# PDF на иврите → исправленный иврит
python3 tbox_refine_standalone.py hebrew_pdf.txt PDF_HE

# Английский PDF → перевод на иврит
python3 tbox_refine_standalone.py english_pdf.txt TRANSLATE_TO_HE

# Русский документ → перевод на английский
python3 tbox_refine_standalone.py russian_doc.txt TRANSLATE_TO_EN
```

### 🎨 Кастомная обработка:

```bash
# Научный стиль
CUSTOM:"Оформи как научную статью с введением, основной частью и заключением"

# Блог-пост
CUSTOM:"Преобразуй в формат поста для блога с подзаголовками и списками"

# Учебные материалы
CUSTOM:"Создай учебное пособие с примерами и упражнениями"
```

## 🎯 Рекомендации

### Для максимального качества:

1. **Используйте MULTILANG** для неизвестных языков
2. **Используйте TRANSLATE_TO_*** для переводов
3. **Используйте CUSTOM** для специфических задач
4. **AUDIO** специально для аудио транскриптов
5. **PDF_HE** для ивритских PDF с огласовками

### Для производительности:

1. **MULTILANG** - самый универсальный
2. **TRANSLATE_TO_RU/EN** - качественные переводы
3. **CUSTOM** - полный контроль над результатом
